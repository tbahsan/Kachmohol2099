## English

Kachmohol 2099 is a browser-based creative sandbox where you shape a luminous biodome with synthetic flora, neon crystals, and anti-gravity technology. It runs entirely in your browser and requires no account or server.

### Version 11 / 1.1 — Stabilization & Personal Sanctuary

- Premium transmissive glass biodome with adaptive solarpunk day and bioluminescent night
- Cinematic bloom, vignette, contact shadows, layered habitat, foliage, particles, and PBR materials
- Lumen Mushroom, Neon Crystal, and Anti-gravity Core
- Select, move, rotate, scale, duplicate, and delete artifacts
- Undo/redo action history and keyboard shortcuts
- Local autosave with IndexedDB
- Versioned JSON import/export
- PNG screenshot capture
- English and Bengali interface
- Creative Home with Continue, Empty Dome, Lumen Garden, and Abyssal Core entry paths
- Guided Create Mode by default, with an Advanced Editor toggle
- One-click smart placement in Guided Mode, with no extra placement step
- Ten data-driven artifacts across Nature, Energy, and Life categories
- Discoverable descriptions, ecosystem impact values, and named interactions
- Reactive artifact animation when an interaction is triggered
- Dynamic Oxygen, Power, Humidity, Biodiversity, and Stability simulation
- Six discoverable cross-object synergies with contextual bonuses
- Gentle balance recommendations and non-punitive ecosystem moods
- Living System observatory with Status, Codex, and Achievements tabs
- Multiple IndexedDB projects with thumbnails, rename, duplicate, open, and delete
- Automatic 30-second recovery snapshots with five-version retention
- Shift-click multi-selection and persistent object groups
- Group-aware dragging, multi-delete, and multi-duplicate
- Mirror, radial ×6, and organic scatter pattern tools
- Front, top, isometric, interior, and underside camera presets
- Procedural Web Audio mixer with rain, wind, station hum, and crystal chimes
- Independent ambience volume controls with no bundled audio assets
- 5, 25, and 50-minute focus sessions with living scene rewards
- 4–4–6 full-screen breathing guide
- Cinematic multi-elevation camera tour in Relax Mode
- Desktop, mobile, square, and viewport wallpaper exports
- Reduced-motion control covering camera, particles, float, clouds, and galaxy
- A single cinematic welcome portal with animated aurora, stars, identity input, projects, and templates
- Explorer identity with four plaque styles, color, privacy, and export controls
- In-world canvas-texture sanctuary plaque supporting Bengali and English names
- Expanded camera zoom from close inspection to wide overview, plus visible zoom/reset/focus controls
- Double-click focus and synchronized OrbitControls camera presets
- Omnidirectional animated shader clouds layered over the 360° day sky
- Reliable Blob-based screenshots with success/error feedback and 4K capability fallback
- Hybrid asset pipeline with bundled CC0 Kenney geometry and runtime Kachmohol PBR materials
- Fixed Shift-click multi-selection, recovery ordering, duplicate onboarding, and excessive modal blur
- Installable PWA with a same-origin offline cache and update notification
- Compressed scene URLs that open safely as new local projects
- Client-side QR codes for shared scenes
- Share-link size guard with JSON fallback
- Profile export/import for achievements, focus, language, and Zen settings
- Curated static gallery loaded from repository JSON
- Service, application, and Three.js bundle separation
- Balanced Habitat, Lumen Garden, and Cosmic Machine procedural generators
- Ten-entry discovery Codex revealed through object interactions
- Six persistent local achievements and gentle ambient events
- Environment particle density and lighting react to ecosystem stability
- Full 360-degree camera orbit and a designed energy underside
- Omnidirectional day cloud ring and spherical Milky Way background
- Non-blocking side catalog that keeps the dome sharp and visible
- Direct manipulation in Guided Mode: grab and drag an artifact across the habitat
- Large Add Object action and an on-demand visual catalog
- Friendly bottom editing tray with simple rotate and size controls
- Animated solarpunk sky with a visible sun and layered moving clouds
- Animated night galaxy with spiral stars, nebula glow, and twinkling starfield
- Optional detailed inspector and technical transform gizmos only in Advanced Mode
- Full-screen Relax Mode with slow cinematic orbit
- Visible author attribution linking to tbahsan
- Localized primary brand name with the alternate language as a subtitle
- Responsive desktop and basic mobile layout

### Controls

| Action | Control |
|---|---|
| Orbit camera | Drag |
| Zoom | Mouse wheel / pinch |
| Select | Click/tap an artifact |
| Move / Rotate / Scale | `G` / `R` / `S` |
| Undo / Redo | `Ctrl/Cmd + Z` / `Ctrl/Cmd + Shift + Z` |
| Duplicate | `Ctrl/Cmd + D` |
| Delete | `Delete` |

### Run in GitHub Codespaces

Open **Code → Codespaces → Create codespace on main**, then run:

```bash
npm install
npm run dev
```

For a production check:

```bash
npm run build
npm run preview
```

Push changes with the Codespaces Source Control panel or:

```bash
git add .
git commit -m "Describe your change"
git push origin main
```

## বাংলা

কাচমহল ২০৯৯ একটি ব্রাউজার-ভিত্তিক ক্রিয়েটিভ স্যান্ডবক্স। এখানে সিন্থেটিক উদ্ভিদ, নিয়ন ক্রিস্টাল ও অ্যান্টি-গ্র্যাভিটি প্রযুক্তি দিয়ে নিজের আলোকিত বায়োডোম তৈরি করা যায়। এটি সম্পূর্ণ ব্রাউজারে চলে; কোনো অ্যাকাউন্ট বা সার্ভার প্রয়োজন নেই।

### বর্তমান প্রোটোটাইপ

- দিন ও নিয়ন-রাতসহ ইন্টারঅ্যাক্টিভ কাচের বায়োডোম
- লুমেন মাশরুম, নিয়ন ক্রিস্টাল ও অ্যান্টি-গ্র্যাভিটি কোর
- অবজেক্ট নির্বাচন, সরানো, ঘোরানো, আকার বদলানো, কপি ও মুছে ফেলা
- Undo/Redo এবং keyboard shortcut
- IndexedDB-তে স্বয়ংক্রিয় local save
- Versioned JSON import/export
- PNG screenshot
- বাংলা ও ইংরেজি interface
- Responsive desktop ও মৌলিক mobile layout

### Codespaces-এ চালানো

রিপোজিটরিতে **Code → Codespaces → Create codespace on main** নির্বাচন করে terminal-এ চালান:

```bash
npm install
npm run dev
```

`main` branch-এ push করলে অন্তর্ভুক্ত GitHub Actions workflow স্বয়ংক্রিয়ভাবে GitHub Pages-এ deploy করবে। Repository Settings → Pages-এ Source হিসেবে **GitHub Actions** নির্বাচন করতে হবে।

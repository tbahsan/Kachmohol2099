# Contributing to Kachmohol 2099

Thank you for helping build Kachmohol 2099. Open an issue before a large change, keep UI text bilingual, test with `npm run build`, and submit focused pull requests.

By contributing, you confirm that you have the right to submit the work and agree that your contribution will be distributed under GPL-3.0-only. Retain applicable copyright and license notices, and document third-party assets and their licenses.

## বাংলা

কাচমহল ২০৯৯-এ অবদান রাখার জন্য ধন্যবাদ। বড় পরিবর্তনের আগে issue খুলুন, UI text বাংলা ও ইংরেজিতে রাখুন, `npm run build` দিয়ে পরীক্ষা করুন এবং ছোট ও নির্দিষ্ট pull request দিন। Contribution জমা দিয়ে আপনি নিশ্চিত করছেন যে কাজটি জমা দেওয়ার অধিকার আপনার আছে এবং এটি GPL-3.0-only-এর অধীনে বিতরণ করা যাবে।
